# ADR 0013：整體介面改成楓之谷風

- 狀態：已接受
- 日期：2026-11-27

## 背景

網站先是極簡工業風（灰底、粗黑線、方角），後來加上 Q彈動畫與貓的語氣。使用者想要的是更有遊戲感、像在楓之谷裡操作的畫面。

## 決定

1. **顏色**：天空藍與草地綠的背景；羊皮紙色的視窗；木頭棕的邊框與導覽列；藍色的按鈕與標題列；金色的強調。
2. **應付金額**：用深藍底、金字的「NPC 對話框」呈現，是總覽最醒目的區塊。
3. **按鈕與提示**：藍色立體按鈕，按下去會沉；提示像遊戲裡的對話框，左側一條色條。
4. **字型**：內文用 Noto Sans TC（粗體做標題），透過 Google Fonts 載入。
5. **class 名稱與 CSS 變數名稱不變**：避免改動模板與 `fun.css`。只改視覺，不改版面結構。
6. **深色模式**：改成夜空版（深藍底、金色邊框）。
7. **導覽列**：目前頁面以金色標出（`aria-current="page"`）。

## 考慮過的替代方案

- **像素風字型整頁使用**（例如 Press Start 2P）：中文沒有對應字型，會退回系統字，效果不一致，所以只保留做為變數，實際上沒有大量使用。
- **另外做一套獨立樣式表**：要維護兩套，不採用。

## 後果

- 正面：整體氣氛更一致，與貓的語氣、貓掌動畫搭配。
- 負面：背景與色彩比較鮮豔，在閱讀大量表格時可能比極簡風累。
- 注意：字型需要連到 Google Fonts，離線時會退回系統字型。
