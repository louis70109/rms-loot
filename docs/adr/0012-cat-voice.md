# ADR 0012：全站文字改用貓的口吻

- 狀態：已接受
- 日期：2026-11-27

## 背景

網站原本的文字是中性的工具用語。使用者希望整個網站有一點個性：像是一隻貓在跟自己人說話，語氣輕鬆、有點調侃，但不失禮。這個口吻要一致，從未登入的擋板到確認框、提示、空白頁都一樣。

## 決定

1. **說話的是貓**：用「喵」、「本喵」、「你」來稱呼使用者。例如「滾去登入喵」、「本喵替你記著」。
2. **只改會對人說話的文字**：提示訊息、空白頁、確認框、按鈕、儲存提示、擋板頁面、儲存空間警告。
3. **表單欄位、表格標題、CSV 格式說明、錯誤細節保持清楚**：例如「手續費」、「A捲, B捲, C捲, tape」、資料庫錯誤原因，不改成貓語氣，避免看不懂。
4. **「分貝」一律寫成「分頁」**：這是使用者的指定用字。
5. **調侃而不辱罵**：可以吐槽、催促，但不用侮辱人身的字眼，也不針對特定人。

## 考慮過的替代方案

- **只在擋板頁用貓語氣**：範圍太小，進站後的語氣會跳得很突兀。
- **全部改掉，包括表單與表格標題**：會影響可讀性，使用者可能找不到欄位，不採用。
- **做成可以切換的模式**：要多一個設定與測試，目前只需要一種風格。

## 後果

- 正面：整個網站有一致的個性，提示與空白頁都比較有趣。
- 負面：之後新增文字時，要記得用同樣的口吻，否則會不一致。
- 注意：測試會檢查部分文字（例如擋板頁的「滾去登入」、儲存空間警告的標題），文字改動時要一起更新測試。
